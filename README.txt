MUTI RACING PROJECT
Personal profile website of Ahmad Mu’thy Anshary.

FILES
- index.html: main website
- style.css: layout, responsive design, and visual effects
- script.js: interactions, gallery, cursor, and audio controls
- assets/: profile/gallery photos, muted RB22 background video, cursor image, and audio files

LOCAL PREVIEW
Open index.html in a modern browser. Internet access is required for Google Fonts.
The background video is muted and loops automatically. Background music starts only after the visitor presses the play button, due to browser autoplay rules. The volume slider controls the music level.

GITHUB PAGES
Upload the CONTENTS of this folder to the root of a GitHub repository. Keep index.html at the repository root and keep the assets folder alongside it. Then enable GitHub Pages from Settings > Pages, deploy from branch main and folder /(root).

NOTE
This is a personal fan-inspired motorsport design, not an official Red Bull Racing website.
